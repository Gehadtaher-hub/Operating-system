Compare page faults and memory-frame states for FIFO and LRU.

03 · Process-State Challenge

Choose the state reached after the displayed event.

04 · Deadlock Safety Analyzer

Use Banker's safety algorithm. Rows represent processes. Separate rows with semicolons and resource values with commas.

05 · Disk Scheduling Simulator

Calculate total head movement and service order for common disk scheduling methods.

06 · Contiguous Memory Allocation

Assign processes to memory blocks using First Fit, Best Fit, or Worst Fit.

07 · Operating Systems Topic Quiz

Thirty questions cover processes, scheduling, synchronization, memory, storage, deadlocks, file systems, and protection.

Generate randomized exams from the full question bank. Practice mode shows explanations after submission. Timed mode automatically submits when time expires.
